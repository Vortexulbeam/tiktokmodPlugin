# TikTok Plugin для Android

Плагин для стандартного TikTok, который добавляет дополнительные настройки и позволяет менять тему приложения.

## Установка

1. Скачайте APK из раздела [Releases](https://github.com/Vortexulbeam/tiktokmodPlugin/releases).
2. Установите APK на устройство Android.
3. Откройте TikTok и настройте плагин.

После установки плагин добавит настройки для TikTok. Доступные параметры зависят от версии приложения.
