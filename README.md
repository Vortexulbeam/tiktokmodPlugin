# TikTok Plugin для Android

Плагин расширяет стандартный TikTok и добавляет настройки, которых может не хватать в обычном приложении. Установите APK, откройте TikTok и настройте нужные функции.

## Возможности

- **Смена региона** — переключайте региональные настройки TikTok.
- **Отключение рекламы** — настройте просмотр ленты без рекламных вставок.
- **Смена тем** — выберите оформление приложения под себя.
- **Автопродление огонька** — поддерживайте серию активности в переписке автоматически.

Доступность функций может зависеть от версии TikTok и Android.

## Установка

1. Скачайте APK из раздела [Releases](https://github.com/Vortexulbeam/tiktokmodPlugin/releases).
2. Установите APK на устройство Android.
3. Откройте TikTok и настройте плагин.
