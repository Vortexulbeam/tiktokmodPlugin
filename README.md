# TikTok Mod для Android — загрузчик модифицированного приложения

Ищете TikTok Mod для Android, мод ТикТока или актуальную версию TikTok Plugin? Этот проект помогает проверить версии и загрузить APK с помощью командной строки. Утилита написана на TypeScript и Bun, поддерживает вывод данных в JSON и подходит для автоматизации.

> Это CLI-загрузчик файлов TikTok Mod и TikTok Plugin, а не само модифицированное приложение. Перед установкой APK проверяйте источник файла и совместимость с устройством.

## Возможности

- Проверка доступной версии TikTok Mod и TikTok Plugin
- Загрузка APK-файла мода, плагина или обоих файлов
- Вывод версии, имени и размера файла в формате JSON
- Индикатор прогресса, повторные попытки при временных ошибках и проверка размера загрузки
- Сохранение загруженных файлов в папку `./apks`
- Запуск из командной строки на Windows и Linux

## Требования

- [Bun](https://bun.sh/) версии 1.4.1 или новее
- Node.js 24 LTS — для инструментов разработки и форматирования

## Установка

Клонируйте репозиторий и установите зависимости:

```bash
git clone <URL-репозитория>
cd <папка-репозитория>
bun install --frozen-lockfile
```

Запускайте команды из корня проекта через `bun run cli`.

## Использование

Проверить доступную версию TikTok Mod:

```bash
bun run cli mod --check
```

Скачать TikTok Mod:

```bash
bun run cli mod --download
```

Проверить TikTok Plugin:

```bash
bun run cli plugin --check
```

Загрузить мод и плагин последовательно:

```bash
bun run cli both --download
```

Получить данные о версии в JSON:

```bash
bun run cli mod --check --json
```

Команда `both --check --json` выводит по одному JSON-объекту на строку: сначала для мода, затем для плагина. Логи и индикатор загрузки отправляются в stderr, поэтому JSON в stdout можно передать другой программе. Загруженные файлы сохраняются в `./apks`.

## Команды и параметры

| Команда или параметр | Назначение |
| --- | --- |
| `mod` | Проверить или загрузить TikTok Mod |
| `plugin` | Проверить или загрузить TikTok Plugin |
| `both` | Выполнить выбранное действие для мода и плагина по очереди |
| `-c`, `--check` | Проверить доступную версию |
| `-d`, `--download` | Загрузить APK-файл |
| `--json` | Вывести данные проверки в JSON |
| `-h`, `--help` | Показать справку CLI |

Для каждой команды укажите `--check` или `--download`.

## Разработка

```bash
bun run check
bun test
```

`bun run check` запускает линтер, проверку форматирования и проверку типов TypeScript. Тесты используют локальные фикстуры и имитацию ответов: они не загружают APK и не обращаются к внешним сайтам.

## Автоматизация и релизы

Автоматические workflow GitHub Actions в этой версии проекта не включены. APK публикуется как вложение к GitHub Release, а исходный код хранится в основной ветке. Доступность и структура сторонних сайтов могут измениться независимо от проекта.

## Безопасность загрузок

CLI получает сведения о файлах и ссылки для загрузки со сторонних сайтов. Авторы репозитория не контролируют эти источники, их содержимое и доступность. Перед установкой самостоятельно проверяйте APK и учитывайте совместимость устройства.
